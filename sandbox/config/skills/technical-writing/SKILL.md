# Technical Writing Skill

## Guidelines

- Use simple, clear technical language
- Be concise in explanations
- Use bullet points sparingly for readability
- Follow Arc42 structure for documentation
- Incorporate C4 architecture models where appropriate

## Arc42 Structure

### Goals

- Clearly state the purpose and objectives
- Explain what the system should achieve
- Keep it brief and focused

### Constraints

- List technical limitations
- Include environmental restrictions
- Note any compliance requirements

### Context

- Describe the system's environment
- Explain interactions with other systems
- Use simple diagrams if helpful

### Solution Strategy

- Outline the approach to meet goals
- Explain key decisions
- Keep it high-level but specific

### Building Blocks

- Use C4 architecture models:
  - Context (Level 1)
  - Containers (Level 2)
  - Components (Level 3)
- Describe major components
- Explain their interactions

### Crosscutting Concerns

- Address non-functional requirements
- Include topics like:
  - Security
  - Performance
  - Logging
  - Monitoring

### Risks

- Identify potential issues
- Assess their impact
- Suggest mitigation strategies

## Writing Style

- Use active voice
- Keep paragraphs short
- Use technical terms appropriately
- Define acronyms on first use
- Use consistent terminology

## Formatting

- Use headings to organize content
- Use bullet points for lists
- Use code blocks for technical details
- Keep line length reasonable

## Review

- Check for clarity and conciseness
- Verify technical accuracy
- Ensure consistent terminology
- Validate structure follows Arc42
